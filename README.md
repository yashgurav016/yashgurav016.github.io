# Yash Gurav - Portfolio

Static site (HTML + CSS + JS). No build step.

Files: index.html, style.css, script.js, assets/ (photo and certificate images), Yash_Gurav_Resume.pdf

Deploy on GitHub Pages: upload all files to a repo -> Settings -> Pages -> Branch: main / root.
Deploy on Netlify: drag and drop this folder at app.netlify.com/drop.
